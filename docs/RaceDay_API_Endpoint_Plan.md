# RaceDay API Endpoint Plan

| HTTP Method | Route                            | Description                                              | Role Required                 | Request Body                                                                                                                      | Expected Response                                                                          |
|-------------|----------------------------------|----------------------------------------------------------|-------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------|
| POST        | /api/auth/register               | Registers a new user (Organiser or Participant)          | None                          | `{ "email": "", "password": "", "firstName": "", "lastName": "", "role": "Participant", "phone": "" }`                            | 201 Created – user object (no password). 400 Validation errors. 409 Email already exists   |
| POST        | /api/auth/login                  | Authenticates user and returns JWT token                 | None                          | `{ "email": "", "password": "" }`                                                                                                 | 200 OK – `{ "token": "", "user": {} }`. 401 Invalid credentials                            |
| GET         | /api/users/me                    | Returns the currently logged-in user’s profile           | Any                           | None                                                                                                                              | 200 OK – user profile. 401 Unauthorized                                                    |
| PUT         | /api/users/me                    | Updates the logged-in user’s profile                     | Any                           | `{ "firstName": "", "lastName": "", "phone": "" }`                                                                                | 200 OK – updated profile. 400 Validation errors. 401 Unauthorized                          |
| GET         | /api/events                      | Lists all events (with optional filters)                 | None / Any                    | None (query: `?type=&location=&date=`)                                                                                            | 200 OK – array of events                                                                   |
| GET         | /api/events/{id}                 | Gets a single event with its categories                  | None / Any                    | None                                                                                                                              | 200 OK – event + categories. 404 Not Found                                                 |
| POST        | /api/events                      | Creates a new event                                      | Organiser                     | `{ "eventName": "", "description": "", "eventDate": "", "location": "", "distanceKm": 0, "eventType": "", "maxParticipants": 0 }` | 201 Created – event. 400 Validation. 403 Forbidden                                         |
| PUT         | /api/events/{id}                 | Updates an existing event                                | Organiser (owner)             | Same as POST                                                                                                                      | 200 OK – updated event. 403 Forbidden. 404 Not Found                                       |
| DELETE      | /api/events/{id}                 | Deletes an event                                         | Organiser (owner)             | None                                                                                                                              | 204 No Content. 403 Forbidden. 404 Not Found                                               |
| GET         | /api/events/{eventId}/categories | Lists all categories for a specific event                | None / Any                    | None                                                                                                                              | 200 OK – array of categories. 404 Event not found                                          |
| POST        | /api/events/{eventId}/categories | Adds a new category to an event                          | Organiser (owner)             | `{ "categoryName": "", "distanceKm": 0, "ageMin": 0, "ageMax": 0, "genderRestriction": "", "entryFee": 0 }`                       | 201 Created – category. 400 Validation. 403/404                                            |
| PUT         | /api/categories/{id}             | Updates a category                                       | Organiser (owner)             | Same as POST                                                                                                                      | 200 OK. 403/404                                                                            |
| DELETE      | /api/categories/{id}             | Deletes a category                                       | Organiser (owner)             | None                                                                                                                              | 204 No Content. 403/404                                                                    |
| POST        | /api/enrolments                  | Participant enrols in an event by selecting a category   | Participant                   | `{ "eventId": 0, "categoryId": 0 }`                                                                                               | 201 Created – enrolment. 400 Validation. 409 Already enrolled / event full. 404 Not Found  |
| GET         | /api/enrolments/me               | Lists all enrolments of the logged-in participant        | Participant                   | None                                                                                                                              | 200 OK – array of enrolments                                                               |
| GET         | /api/events/{eventId}/enrolments | Lists all enrolments for a specific event                | Organiser (owner)             | None                                                                                                                              | 200 OK – array of enrolments. 403/404                                                      |
| DELETE      | /api/enrolments/{id}             | Cancels an enrolment                                     | Participant (own) / Organiser | None                                                                                                                              | 204 No Content. 403/404                                                                    |
| POST        | /api/results                     | Captures a result for an enrolment                       | Organiser                     | `{ "enrolmentId": 0, "finishTime": "", "position": 0, "status": "Finished", "notes": "" }`                                        | 201 Created – result. 400 Validation. 404 Not Found. 409 Result already exists             |
| GET         | /api/results/me                  | Returns the logged-in participant’s race results         | Participant                   | None                                                                                                                              | 200 OK – array of results                                                                  |
| GET         | /api/events/{eventId}/results    | Returns all results for an event                         | Organiser / Any               | None                                                                                                                              | 200 OK – array of results. 404 Not Found                                                   |
| GET         | /api/events/{eventId}/images     | Lists images for an event                                | None / Any                    | None                                                                                                                              | 200 OK – array of images                                                                   |
| POST        | /api/events/{eventId}/images     | Uploads an image for an event (for Part 3)               | Organiser                     | `{ "imageUrl": "", "caption": "", "isPrimary": false }`                                                                           | 201 Created. 403/404                                                                       |
